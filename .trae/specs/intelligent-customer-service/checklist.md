
# 智能客服后端 - 验证清单

## 核心功能验证
- [ ] 配置管理器能正确加载 YAML 文件并支持环境变量替换
- [ ] 配置修改能触发热重载，无需重启服务
- [ ] ProviderManager 能管理多个供应商和模型别名
- [ ] OpenAICompatibleProvider 能正常调用 API
- [ ] TaskExecutor 能执行任务并在失败时降级
- [ ] 短期记忆能正确存储和加载会话消息
- [ ] 记忆冻结时不允许写入新消息
- [ ] 记忆超过存储限制时能正确凋落低价值消息
- [ ] 前置安全审查能拦截违规输入
- [ ] 后置安全审查能替换违规输出
- [ ] 知识库检索能正常从 Dify 获取片段
- [ ] Agent 基础对话流程能正常工作
- [ ] 会话转接时能正确清空和冻结记忆
- [ ] 转接中的消息能正确转发到外部接口
- [ ] 管理 API 的配置管理接口能正常工作
- [ ] 管理 API 的会话管理接口能正常工作
- [ ] 管理 API 的健康检查接口能正常响应

## 代码质量验证
- [ ] 所有模块有对应的单元测试
- [ ] 代码遵循项目的编码规范
- [ ] 关键模块有清晰的注释和文档
- [ ] 没有硬编码的敏感信息（API密钥等）
- [ ] 错误处理完善，有适当的日志记录

## 性能验证
- [ ] 简单请求响应时间 &lt; 3s
- [ ] 复杂请求响应时间 &lt; 10s
- [ ] 系统能支持至少 100 并发会话


# 智能客服后端 - Verification Checklist

## 核心功能验证
- [ ] 配置管理器能正确加载YAML文件并支持环境变量替换
- [ ] 配置修改能触发热重载，无需重启服务
- [ ] ProviderManager能管理多个供应商和模型别名
- [ ] OpenAICompatibleProvider能正常调用API
- [ ] TaskExecutor能执行任务并在失败时降级
- [ ] 短期记忆能正确存储和加载会话消息
- [ ] 记忆冻结时不允许写入新消息
- [ ] 记忆超过存储限制时能正确凋落低价值消息
- [ ] 前置安全审查能拦截违规输入
- [ ] 后置安全审查能替换违规输出
- [ ] 知识库检索能正常从Dify获取片段
- [ ] Agent基础对话流程能正常工作
- [ ] 会话转接时能正确清空和冻结短期记忆
- [ ] 转接中的消息能正确转发到外部接口
- [ ] 管理API的配置管理接口能正常工作
- [ ] 管理API的会话管理接口能正常工作
- [ ] 管理API的健康检查接口能正常响应
- [ ] 主API能接收user_id并正确映射到会话
- [ ] 同一user_id能复用同一会话
- [ ] 会话超时时能自动清理
- [ ] 用户ID与会话映射能正确存储在Redis中
- [ ] 对话记录模块能完整记录会话历史
- [ ] 对话记录与短期记忆分离存储
- [ ] 能获取指定会话的完整对话记录
- [ ] 对话记录能与短期记忆同步更新
- [ ] 对话记录不进行凋落，完整保存
- [ ] 所有外部API调用输出包含输出内容和用户ID
- [ ] 转接人工时发送的数据包含用户内容、用户ID和完整对话记录

## 代码质量验证
- [ ] 所有模块有对应的单元测试
- [ ] 代码遵循项目的编码规范
- [ ] 关键模块有清晰的注释和文档
- [ ] 没有硬编码的敏感信息（API密钥等）
- [ ] 错误处理完善，有适当的日志记录

## 性能验证
- [ ] 简单请求响应时间 &lt; 3s
- [ ] 复杂请求响应时间 &lt; 10s
- [ ] 系统能支持至少100并发会话
